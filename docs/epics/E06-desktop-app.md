# E06: Desktop App

**Goal:** Expose scanner and cleanup capabilities through a clear Tauri UI.

## Stories

### E06-S01 Initialize the Tauri shell
**Status:** todo

**Acceptance criteria**
- App launches locally on Windows 10 and 11 development environments.
- Scanner core is invoked through narrow commands.

### E06-S02 Build dashboard and scan progress
**Status:** todo

**Acceptance criteria**
- User can start a scan and see per-profile progress and warnings.
- Scan cancellation leaves profiles untouched.

### E06-S03 Build layered scan results
**Status:** todo

**Acceptance criteria**
- Default summary, expandable details, and optional expert view are available.
- Findings group by browser, profile, site, category, and confidence.

### E06-S04 Build cleanup preview flow
**Status:** todo

**Acceptance criteria**
- Review, Balanced, and Aggressive modes are selectable.
- Warnings and locked-item choices appear before execution.

### E06-S05 Build settings and privacy controls
**Status:** todo

**Acceptance criteria**
- Rule version, update state, and separate telemetry and diagnostic opt-ins are visible.
- Both opt-ins default to disabled.
